# VELMORA — The Poster for a Place That Isn't There

A travel poster for an invented place, drawn from scratch with PIL
(stdlib + Pillow only, no network, fully deterministic). Entry for the
[make.fun bounty](https://make.fun/bounty/the-poster-for-a-place-that-i-2-20261121-0539).

**The place:** Velmora, a cliff town where the sea falls UP — ribbons of
water rise from the bay into the evening sky, past a lighthouse and a
whitewashed town, under a golden sunset. The poster's one landmark is the
upward sea itself; the name is set into the picture, with no invented
quotes, star ratings or other copy.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, ≤1 MiB) — or `$MAKEFUN_OUTPUT_DIR/entry.png`
when that is set — plus a local `entry.png` for inspection.
